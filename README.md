# Dra. Valquíria Campos

Prévia de apresentação profissional e procedimentos estéticos. Projeto independente em React, TypeScript e Vite, a partir da estrutura do site da Dra. Michele Pira.

```sh
npm ci
npm run dev
npm run check
npm run build
```

O build gera `dist/`. Na Vercel, importe este repositório como um novo projeto Vite. Para definir a URL canônica, configure `VITE_SITE_URL` com a origem HTTPS escolhida. O projeto vem desindexado como prévia. Use `src/config/site.ts` para ajustar e confirmar os dados de contato.
